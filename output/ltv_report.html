📐 LTV 定义与指标说明

LTV (LifeTime Value) = 用户从开始使用到流失/观察期结束，为产品贡献的总价值

计算公式：LTV = Σ 用户每月付费 × 生命周期月数

关键指标：
• 平均 LTV = 总营收 / 总用户数（所有用户的平均贡献）
• 付费用户 LTV = 付费用户总营收 / 付费用户数
• 月均 ARPU = 平均 LTV / 平均生命周期（每月每用户平均收入）
• 付费率 = 付费用户数 / 总用户数
📐 指标关系

付费率 = 付费用户 / 总用户  →  1,976 / 5,000 = 39.5%
